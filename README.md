# Embedding

This project demonstrates semantic sentence similarity using **embeddings** generated with the `all-MiniLM-L6-v2` model from `sentence-transformers`. The project includes cosine similarity comparisons and 2D visualizations created with **t-SNE**.

---

## Dependencies

- Python ≥ 3.8
- `sentence-transformers`
- `scikit-learn`
- `matplotlib`

---

## Install dependencies

```bash
pip install sentence-transformers scikit-learn matplotlib
